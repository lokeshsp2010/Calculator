# Simple Calculator 

A lightweight calculator built using Python. This project was developed to practice fundamental programming concepts.
## Features

**Basic Arithmetic:** Supports Addition, Subtraction, Multiplication, and Division.
**Continuous Execution:** Runs in a `while` loop, allowing you to perform multiple calculations without having to restart the program.

### Requirements 
You will need Python 3 installed on your machine to run this script.

### Installation & Execution
1. Download the `calculator.py` file.
2. Open the CMD prompt.
3. Navigate to the directory where the file is saved.
4. Run the script using the following command:
           "python calculator.py"
